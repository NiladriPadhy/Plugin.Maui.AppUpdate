## 1.0.0

- Cross-platform in-app updates for .NET MAUI on Android and iOS
- Common `CheckAsync` / `StartAsync` API
- Google Play immediate and flexible In-App Updates
- App Store version check via the iTunes lookup API
- Mandatory and recommended prompts, including Play priority 4–5
- Minimum supported version, release notes, and maintenance mode
- Recommended-update postponement with a persisted cooldown
